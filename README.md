# 🛒 Blinkit Sales & Outlet Performance Dashboard — Power BI

## 📊 Project Overview

An interactive **Blinkit Sales & Outlet Performance Dashboard** built using **Microsoft Power BI** to analyze sales performance, outlet characteristics, product categories, and customer ratings.

The dashboard transforms sales data into meaningful business insights through interactive KPIs, filters, and visualizations.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Track key sales KPIs
- Understand outlet performance
- Compare sales across outlet locations and sizes
- Analyze product and item-type performance
- Study sales trends based on outlet establishment
- Analyze customer ratings and item visibility

## 📌 Key KPIs

- 💰 **Total Sales**
- 📈 **Average Sales**
- 🛒 **Number of Items**
- ⭐ **Average Rating**

## 📈 Dashboard Analysis

### Sales Performance

- Total and average sales
- Sales by outlet establishment
- Sales by outlet location

### Product Analysis

- Sales by item type
- Item visibility analysis
- Fat-content based sales performance

### Outlet Analysis

- Outlet size performance
- Outlet location tier
- Outlet establishment trends

### Customer Metrics

- Average customer rating
- Item count and sales performance
